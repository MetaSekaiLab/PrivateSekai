# Private Sekai

## 项目简介

本项目用于模拟游戏 **初音未来 -歌姬计划- （初音ミク -プロジェクト ディーヴァ-，Hatsune Miku: Project DIVA）** 游戏测试服务端，供个人技术研究、协议分析、逆向学习等用途。所有功能仅限于本地测试，严禁用于任何形式的公开传播、开服或商业用途。

## 游戏介绍


>
> ​	《初音未来 -歌姬计划-》系列（繁体中文：初音未来 -名伶计划-系列，日文：初音ミク -Project DIVA- シリーズ）是由SEGA主导开发的音乐节奏游戏系列。游戏初登场于PSP平台，后来在PSV、PS3、街机、PS4、Switch、PC等平台不断推出新作。系列后来扩展为SEGA feat. HATSUNE MIKU Project。

> ​	此系列首款游戏《初音未来 -歌姬计划-》发布于2009年7月2日，由DINGO和SEGA共同开发，几年后DINGO破产，游戏变为由世嘉独立主导开发。
>
> ​	游戏名称中“DIVA”是歌剧中的女主唱的意思，并且游戏以Crypton Future Media株式会社旗下的虚拟歌手初音未来命名。该游戏系列的绝大多数曲目均由VOCALOID虚拟歌手初音未来、镜音铃·连、巡音流歌、MEIKO和KAITO演唱。

### 当前主要缺口

- **普通演出奖励仍有样本硬编码**：评分掉落只覆盖两个谱面等级／评分组合，其余返回空；随机资源池和权重尚未还原。B 档官方对拍已确认漏发经验，不能把当前结算视为完整实现。
- **每日奖励和多人流程未完成**：每日加成由多人／Cheerful 通关触发，普通单人不触发；当前剩余次数误用体力消耗，不能改为固定次数。基础实时通信已实测，但尚不能连接房间或完成多人演出。
- **挑战循环未完成**：完整结算、后续出勤、跨日、EX、Auto、高档经验和掉落仍待补齐。
- **兑换、资源与任务覆盖有限**：材料兑换的周期和限量、部分活动奖励资源、称号升级、角色满级／解锁奖励及部分角色任务合并领奖仍有限制。
- **泛化与官方验证分开记录**：评分和成就已使用完整 master 门槛；收集任务及新手总任务也已支持多门槛，但部分高门槛只有本地测试和逆向依据，尚无官方实测。

最近的业务验证通过 800 项检查；实时 UDP 迭代通过 438 项客户端检查、Server 构建与协议检查。三槽称号六份官方专项对拍无差异，实时认证、握手和加密 Ping 已有官方成功样本；重传和分片目前由本地检查验证。这些结果只证明各检查覆盖的范围，不表示整款游戏或所有 API 已兼容。协议检查仍提示现有模板存在未映射字段。
